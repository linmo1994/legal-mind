# 向量化文档功能说明

## 功能概述

本系统实现了基于ChromaDB的文档向量化功能，支持：
- 文档向量化存储
- 相似文档搜索
- 向量数据库持久化
- 通过客户端页面管理向量化文档

## 安装依赖

### 方法1：使用安装脚本
```bash
./安装向量化依赖.sh
```

### 方法2：手动安装
```bash
pip3 install chromadb>=0.4.0 sentence-transformers>=2.2.0
```

**注意：** 首次运行时会自动下载嵌入模型（约400MB），请确保网络连接正常。

## 使用说明

### 1. 启动服务

确保MCP服务端已启动：
```bash
python3 server/mcp_server.py
```

### 2. 访问向量化页面

在浏览器中访问：
```
http://localhost:8888/vectorize.html
```

或通过主页导航：
```
http://localhost:8888/index.html
```
然后点击"向量化文档"按钮

### 3. 功能使用

#### 向量化文档
1. 输入文档ID（唯一标识）
2. 输入文档标题（可选）
3. 输入文档内容或上传文件
4. 点击"开始向量化"

#### 搜索文档
1. 输入搜索查询
2. 设置返回结果数量
3. 点击"搜索"

#### 删除文档
1. 输入要删除的文档ID
2. 点击"删除文档"

## 技术实现

### 服务端

- **向量化服务模块**: `server/vector_service.py`
  - 使用ChromaDB进行向量存储
  - 支持持久化到本地文件（`./chroma_db`目录）
  - 使用sentence-transformers生成嵌入向量

- **MCP工具**: 在`server/mcp_server.py`中实现
  - `vectorize_document`: 向量化文档
  - `search_documents`: 搜索相似文档
  - `delete_document`: 删除文档
  - `get_vector_db_info`: 获取数据库信息

### 客户端

- **向量化页面**: `vectorize.html`
  - 文档上传和向量化
  - 相似文档搜索
  - 文档管理

## 数据存储

向量数据存储在 `./chroma_db` 目录中，支持持久化。即使服务重启，数据也不会丢失。

## 注意事项

1. 首次使用需要下载嵌入模型，可能需要几分钟时间
2. 向量数据库存储在服务端本地，确保有足够的磁盘空间
3. 文档会被自动分割成多个文本块进行向量化，以提高搜索精度
