# 账号下拉收纳「管理后台」设计

**日期：** 2026-09-05  
**状态：** 已定稿  
**范围：** 壳层顶栏（`index.html`）账号菜单；移除首页独立管理入口。

---

## 1. 背景与目标

### 现状

- 壳层顶栏有独立「管理后台」按钮（`navAdminBtn`），与用户名下拉并列。
- 用户名下拉已有「联系我们」「退出」。
- `home.html` 另有 `adminTab`（嵌在壳层 iframe 时已隐藏）。

### 目标

1. 顶栏不再单独展示「管理后台」。
2. 已登录用户点击右上角姓名下拉，可见：**管理后台**（有权限时）、**联系我们**、分隔线、**退出**。
3. 无管理权限用户不显示「管理后台」项。
4. 删除首页独立「管理后台」入口，统一从壳层下拉进入。

### 非目标

- 不改管理后台内部页面与权限模型。
- 不抽离 `shell-nav.js` / 通用 AccountMenu 组件（本期最小改动）。
- 不改联系我们弹窗内容与退出登录 API。

---

## 2. 决策摘要

| 议题 | 决定 |
|------|------|
| 实现方式 | 最小改动：复用现有 `navUserDropdown` |
| 无权限 | 隐藏「管理后台」（等同原顶栏 `canOpenAdmin()`） |
| 菜单顺序 | 管理后台 → 联系我们 → 分隔线 → 退出 |
| 首页 adminTab | 删除（含相关 JS/CSS） |

---

## 3. 行为细节

### 3.1 顶栏结构

- **未登录：** Logo +「登录」。
- **已登录：** Logo + 用户名按钮（含 ▾）；无独立「管理后台」按钮。

### 3.2 下拉菜单

| 项 | 可见条件 | 点击行为 |
|----|----------|----------|
| 管理后台 | 已登录且 `canOpenAdmin()` | 关闭下拉 → `loadPage('admin.html')` |
| 联系我们 | 已登录 | 关闭下拉 → 打开现有联系我们弹窗 |
| （分隔线） | 已登录（始终显示于「退出」之上） | — |
| 退出 | 已登录 | 关闭下拉 → `LegalMindAuth.logout()` → 同步导航 → `loadPage('home.html')` |

`canOpenAdmin()` 保持现有判定：`page.admin` 或 `cap.user_manage` / `cap.case_manage` / `cap.role_manage`。

### 3.3 关闭下拉

保留现有：点击菜单外、Esc、选择菜单项后关闭。

### 3.4 首页

移除 `adminTab` DOM、点击处理，以及仅服务于该按钮的样式。直接打开 `home.html` 时也不再提供页内管理入口（须经壳层 `index.html` 使用完整产品导航）。

---

## 4. 文件改动

| 文件 | 责任 |
|------|------|
| `index.html` | 移除 `navAdminBtn`；下拉增加管理项与分隔；`syncShellNav` 控制显隐；绑定点击 |
| `index.css` | 下拉分隔线样式；清理顶栏管理按钮相关样式（若有） |
| `home.html` | 删除 `adminTab` |
| `home.js` | 删除 adminTab 显隐与点击 |
| `home.css` | 删除 `.admin-tab*` 样式 |

---

## 5. 验收

1. 有管理权限账号：顶栏无「管理后台」按钮；下拉含管理后台 / 联系我们 / 分隔 / 退出；点管理后台进入 `admin.html`。
2. 无管理权限账号：下拉无「管理后台」，仅联系我们 / 分隔 / 退出。
3. 未登录：无用户下拉，有「登录」。
4. 首页（经壳层）不再出现管理后台按钮。
5. 联系我们弹窗、退出登录行为与改前一致。

---

## 6. 测试说明

手工冒烟即可（无后端契约变更）。建议用 `director`（有权限）与一无管理权限账号对照下拉内容。
