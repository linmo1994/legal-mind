# 相关资料侧栏：气泡 Tab + 右侧面板

**日期：** 2026-09-07  
**状态：** 待审阅  
**分支建议：** 在 `feat/agent-orchestration-loop` 上继续  
**范围：** `mcp_client` 多轮对话页引用展示与侧栏；不改检索 / PnE / 引用生成语义。

**相关：**  
- 编排抽屉：`docs/superpowers/specs/2026-09-06-orchestrate-drawer-tab-design.md`（过程入口仍为顶端「执行过程」+ 底部抽屉；本规格另开「相关资料」）  
- 引用 file_id：`docs/superpowers/specs/2026-09-06-citation-fileid-and-retrieve-plan-design.md`

## 1. 背景与目标

### 现状

- 助手气泡在正文下渲染内联 `.cite-list`（「引用」+ 可点标题列表）。
- 正文内可对法规/案例名做 linkify，点击打开 `openCitationPreview`。
- 「执行过程」使用独立底部抽屉；主栏全宽。

### 问题

- 引用列表挤占气泡阅读区，与示例产品形态不一致。
- 缺少「已阅读 X 条法规，Y 个案例」汇总入口与右侧资料浏览。

### 目标

1. **去掉**气泡内 `.cite-list`，改为正文下方胶囊 Tab：「已阅读 X 条法规，Y 个案例」。
2. 点击 Tab 打开右侧 **「相关资料」** 面板，内分 **法规 / 案例** 两档。
3. **宽屏（≥900px）** 双栏推开；**窄屏（&lt;900px）** 右侧浮层 + 遮罩。
4. 正文内联引用链接行为不变（仍只开原文预览，不联动侧栏）。

### 非目标

- 扩展 citation 后端字段（有效状态、发文机关、实施时间等）。
- 改 `hits_to_citations`、检索过滤、编排过程抽屉。
- 首页单轮会话布局。
- 点赞/复制逻辑变更（复制仍排除过程/Tab/侧栏 chrome；复制成功 toast 保持）。

---

## 2. 决策摘要

| 议题 | 决定 |
|------|------|
| 气泡内引用列表 | 移除；仅保留 Tab + 侧栏 |
| 侧栏实现 | 新建 `#relatedMaterials`，不复用 `#orchestrateWorkbench` |
| 宽屏 | 主栏 + 右栏推开（约 360–400px） |
| 窄屏 | 右浮层 + 遮罩；主栏全宽 |
| 内联链接 | 仍 `openCitationPreview` |
| 新一轮有引用 | 更新 Tab/缓存，不自动打开侧栏 |
| 空引用 | 不渲染 Tab |
| 一侧为 0 | Tab 仍显示，如「已阅读 0 条法规，3 个案例」 |

## 3. 页面骨架

```text
宽屏 · 侧栏关闭：
┌─────────────────────────────────────────────┐
│ 主栏全宽 · 消息列表                           │
│   助手气泡：正文 → [已阅读 X 条法规，Y 个案例] │
│            → 点赞 / 反点赞 / 复制              │
└─────────────────────────────────────────────┘

宽屏 · 侧栏打开：
┌──────────────────────────┬──────────────────┐
│ 主栏（变窄）               │ 相关资料     [×] │
│  …气泡 Tab…               │ [法规] [案例]     │
│                           │ 1. 标题…          │
│                           │    snippet…       │
└──────────────────────────┴──────────────────┘

窄屏 · 侧栏打开：
┌─────────────────────────────────────────────┐
│ 主栏全宽 + 半透明遮罩                          │
│                          ┌────────────────┐ │
│                          │ 相关资料   [×]  │ │
│                          │ [法规][案例]    │ │
│                          └────────────────┘ │
└─────────────────────────────────────────────┘
```

- 断点：`900px`（与既有编排宽窄习惯对齐即可；实现时用同一常量）。
- 「执行过程」底部抽屉保持独立；两者可先后打开，本版不强制互斥（若同时打开，z-index 保证可关即可）。

## 4. 交互

| 操作 | 行为 |
|------|------|
| 点某条「已阅读…」Tab | 将该消息 citations 载入侧栏 → 打开；该 Tab `aria-pressed=true` |
| 再点**同一条**且侧栏已开 | 关闭侧栏 |
| 点**另一条**消息的 Tab | 切换数据源并重绘，侧栏保持打开 |
| 关闭钮 / Esc / 窄屏遮罩 | 关闭侧栏 |
| 新一轮编排/回复完成 | 挂上或更新 Tab；**不**自动 `open` |
| 切换会话 / 清空聊天 | 关闭侧栏并清空按消息绑定的缓存 |
| 正文 `.cite-inline` | 仅 `openCitationPreview` |

气泡内顺序：**正文 → 外源提示（如有）→ 已阅读 Tab（如有）→ 消息操作栏**。

---

## 5. 侧栏内容

- 标题：「相关资料」；关闭按钮。
- 分段：**法规** | **案例**。默认：有法规则选法规，否则案例。
- 列表项：序号、标题（法规可拼接 `article`）、`snippet`（截断展示）。
- 有 `file_id`：点击 → `openCitationPreview(cite)`；无：禁用并提示「未关联源文件」。
- 空分段：「暂无法规」/「暂无案例」。

分类规则：`doc_type === 'case'` → 案例；`doc_type === 'law'` → 法规；其余缺省归法规（与现有 law/case 合流列表兼容）。计数与列表同一规则，保证 Tab 数字与侧栏一致。

---

## 6. 数据与接线

- 仍使用现有 `normalizeCitationsList` / `collectOrchestrateCitations` 结果；条目字段：`doc_type`, `title`, `article`, `snippet`, `file_id`, …
- 按消息元素或 `data-turn-id` / 生成的 `data-cite-source-id` 缓存当前打开源，供多气泡切换。
- `renderAssistantAnswerWithCitations`：**不再**调用 `renderCitationList`；在消息宿主挂载「已阅读…」Tab（无引用则不挂）。`renderCitationList` 可暂时保留但默认路径不使用。
- Tab 节点建议 class：`related-materials-tab`；复制纯文本时与 `.cite-list` 一并排除。
- 覆盖路径：编排成功、`addMessage`、`addCombinedMessage`、`restoreHistoryMessage`。

## 8. 测试要点

1. 法规+案例：Tab「已阅读 N 条法规，M 个案例」；侧栏两档条目正确。  
2. 仅案例：Tab 含「0 条法规」；法规档空态。  
3. 无引用：无 Tab。  
4. 宽屏打开推开主栏；窄屏浮层+遮罩。  
5. 同 Tab 再点 / Esc / 关闭可关；切换消息 Tab 换内容。  
6. 内联链接仍打开预览。  
7. 复制正文不含 Tab 文案；复制成功仍 toast「已复制成功」。

---

## 9. 验收

- 多轮页有引用时，气泡底出现汇总 Tab，无内联「引用」列表。  
- 点 Tab 出现「相关资料」，法规/案例可切换。  
- 宽/窄行为符合第 3 节；过程抽屉与复制反馈不受回归。
