# 法律文书生成指南

与 MCP 提示词 `gen_legal_doc_guide` 覆盖同一类任务；有本 Skill 时优先按本节执行，不要再调用该 MCP 提示词。

1. 首先检索并获取对应的法律文书模板。
2. 分析模板中的占位符，提取需要填充的信息。
3. 根据用户提供的信息，填充模板占位符；缺失处写「待补充」，不得编造。
4. 检查文书的格式规范和法律术语使用。
5. 确保文书符合相关法律法规要求（法条只引用已检索或用户提供的条文）。
6. 生成完整的法律文书正文。

注意事项：

- 保持法律文书的正式性和规范性。
- 确保所有必要信息都已填写或标明待补充。
- 检查日期、金额等关键信息的准确性。
- 使用标准的法律术语和表达方式。
